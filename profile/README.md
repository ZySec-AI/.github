## Flagship Product — Relata DB

> **Frontier Sovereign Intelligence Database** · [relatadb.dev](https://relatadb.dev) · [@relatadb](https://github.com/relatadb)

Relata DB is ZySec.AI's core data infrastructure — a governed temporal knowledge database where **policy, provenance, and bi-temporal history are in the query path**, not bolted on top.

Built for intelligence, security, and compliance workloads that cannot compromise on auditability or data sovereignty.

- **Bi-temporal** — query any point in history; valid-time and system-time on every row
- **Governed** — Cedar-inspired ABAC, cell masking, PURPOSE-tagged audit in the execution path
- **Multi-modal** — relational, graph, vector, full-text, and identity in one self-hosted store
- **Protocol-compatible** — Postgres wire, Bolt, S3, Redis, MongoDB, ClickHouse, Arrow Flight, MCP

```bash
curl -sSL https://relatadb.dev/install.sh | bash && relata serve
```

👉 [GitHub: relatadb](https://github.com/relatadb) · [Docs & Downloads](https://relatadb.dev)
